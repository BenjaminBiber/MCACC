## Global Constraints

- **Target:** `net10.0`, `LangVersion latest`, `Nullable enable`, `ImplicitUsings enable`, `TreatWarningsAsErrors true`. SDK pinned via `global.json` → `10.0.301`, `rollForward: latestFeature`.
- **Central package management** (`Directory.Packages.props`). Versions:
  - Avalonia, Avalonia.Desktop, Avalonia.Themes.Fluent, Avalonia.Fonts.Inter, Avalonia.Headless.XUnit → **12.1.3**
  - CommunityToolkit.Mvvm **8.4.2**
  - System.Management **10.0.12**
  - xunit.v3 **3.2.2**, xunit.runner.visualstudio **3.1.5**, Microsoft.NET.Test.Sdk **18.10.1**
  - Shouldly **4.3.0**
  - If a pinned version fails to restore, use the closest existing stable version and report it. Never use FluentAssertions.
- **Projects and responsibilities:**
  - `src/Mcacc.Core`: UI-free and never starts processes. It owns all pure logic and does file IO only for config, cache, launch files, copying and readers.
  - `src/Mcacc.Platform`: the only place that touches `System.Diagnostics.Process`, WMI, libc, Keychain or `HttpClient`.
  - `src/Mcacc.App`: Avalonia 12, MVVM.
  - Tests: `tests/Mcacc.Core.Tests`, `tests/Mcacc.Platform.Tests` (OS-conditional smoke tests), `tests/Mcacc.App.Tests`.
- **Namespaces** follow folders: `Mcacc.Core.Config`, `Mcacc.Platform.Windows`, `Mcacc.App.ViewModels`, …
- **Tests:** xUnit v3 + Shouldly. Follow TDD (red → green) for every Core unit. File-system tests use a unique temp directory per test and clean up; set `MCACC_HOME` / constructor paths, never touch the real `~/.mcacc`, `~/.claude`, or `%APPDATA%\Claude`.
- **Data root:** `~/.mcacc` (Windows `%USERPROFILE%\.mcacc`), overridable by env var `MCACC_HOME`. Layout:
  ```
  config.json, config.json.bak, config.json.corrupt-<yyyyMMddHHmmss>
  usage-cache.json
  profiles/<id>/desktop     # Electron --user-data-dir
  profiles/<id>/claude      # CLAUDE_CONFIG_DIR
  launch/<id>.cmd | launch/<id>.command
  logs/mcacc-yyyyMMdd.log
  ```
- **Default account:**
  - `id "standard"`, `name "Standard"`, `color "#D97757"`, `isDefault true`. Exactly one default exists; it cannot be removed.
  - Its Desktop starts **without** `--user-data-dir`. Its Claude Code runs **with `CLAUDE_CONFIG_DIR` removed**.
  - Its data (`%APPDATA%\Claude`, `~/.claude`, `~/.claude.json`) is never deleted or written by MCACC.
- **Env hygiene:** always remove `CLAUDECODE`, `CLAUDE_CODE_ENTRYPOINT`, `CLAUDE_CODE_SSE_PORT` from launched processes/scripts. For the default account also remove `CLAUDE_CONFIG_DIR`.
- **Secrets:** OAuth tokens are read only, never written, never logged, never cached, never sent anywhere except `https://api.anthropic.com/api/oauth/usage`. `~/.claude.json` and `.credentials.json` are never written. No token refresh.
- **Language:** All user-facing strings are German and live in `src/Mcacc.App/Localization/Texts.cs`. Core returns enums/result types, never German text. Code, identifiers and comments are in English; comments are sparse.
- **Claude Desktop facts:**
  - Windows MSIX alias: `%LOCALAPPDATA%\Microsoft\WindowsApps\claude-desktop.exe`.
  - Squirrel fallback: `%LOCALAPPDATA%\AnthropicClaude\claude.exe`.
  - MSIX package family name: `Claude_pzs8sxrjxfjjc`.
  - macOS bundle: `/Applications/Claude.app` (bundle id `com.anthropic.claudefordesktop`, to be confirmed by the spike).
- **Commits:** small, imperative subject (`feat(core): …`, `test(core): …`, `chore: …`), each message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. The git identity is already configured in the repo; never change git config.

**Paths/**
- `PathStyle` enum: `Windows`, `Posix`.
  - Extension `char Separator(this PathStyle)`.
  - `string Join(this PathStyle, params string[] parts)` joins with the style's separator, trims duplicate separators at the joints and does not use `System.IO.Path`, so both styles are testable on any OS.
- `PlatformInfo` sealed record:
  - Properties: `OsKind Os`, `string HomeDir`, `string RoamingAppData`, `string LocalAppData`.
  - `PathStyle PathStyle => Os == Windows ? Windows : Posix`.
  - Static `PlatformInfo.Current()` reads `Environment.GetFolderPath` / `OperatingSystem.Is*`.
- `McaccPaths` sealed class:
  - Constructor `(string root, PathStyle style)`.
  - Static `FromEnvironment(PlatformInfo info, Func<string, string?> getEnv)`: root = `MCACC_HOME` if non-empty else `Join(home, ".mcacc")`.
  - Properties: `Root`, `ConfigFile`, `ConfigBackupFile`, `UsageCacheFile`, `ProfilesDir`, `LaunchDir`, `LogsDir`.
  - Methods: `ProfileDir(id)`, `DesktopDataDir(id)`, `ClaudeConfigDir(id)`.
- `AccountPaths` sealed record:
  - `string? DesktopUserDataDir`: null means use the app default, i.e. no flag.
  - `string? ClaudeConfigDir`: null means unset the variable.
  - `string EffectiveClaudeDir`: the default is `~/.claude`.
  - `string ClaudeJsonFile`: the default is `~/.claude.json`; for a profile it is `<claudeDir>/.claude.json`.
  - `string CredentialsFile`: `<EffectiveClaudeDir>/.credentials.json`.
  - `IReadOnlyList<string> DesktopDataDirs`: for the default account, the candidate real locations in preference order. Windows: `<LocalAppData>\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude`, then `<RoamingAppData>\Claude`. macOS: `~/Library/Application Support/Claude`. For a profile: `[DesktopUserDataDir]`.
- `AccountPathResolver` sealed class: constructor `(McaccPaths paths, PlatformInfo info)`, method `AccountPaths Resolve(Account a)`. Pure, no IO.
- `PathComparer` static:
  - `string Normalize(string path, PathStyle style)`: unify separators (Windows: `/`→`\`), collapse duplicates, trim trailing separators except a root.
  - `bool Same(string a, string b, PathStyle style)`: `OrdinalIgnoreCase` on the normalized paths.
  - `bool IsStrictlyUnder(string child, string parent, PathStyle style)`: handles `..` segments by resolving them textually and rejects equality.

**Config/**
- `McaccJsonContext`:
  - Source-generated `JsonSerializerContext` for `AppConfig` (and later `UsageCacheFile`, Task 8 adds it).
  - Options: camelCase properties, `WriteIndented`, enums as camelCase strings, `DefaultIgnoreCondition = WhenWritingNull`.
- `ConfigLoadStatus` enum: `Loaded`, `CreatedDefault`, `RecoveredFromBackup`, `ResetAfterCorruption`, `NewerVersionReadOnly`.
- `ConfigLoadResult` sealed record: `AppConfig Config`, `ConfigLoadStatus Status`, `bool IsReadOnly`, `IReadOnlyList<string> Repairs`.
- `IConfigStore` (in `Abstractions/`): `ConfigLoadResult Load()`, `void Save(AppConfig config)`.
- `ConfigStore : IConfigStore`: constructor `(McaccPaths paths, TimeProvider? time = null)`.
  - **Missing file:** `DefaultConfigFactory.Create()`, saved, status `CreatedDefault`.
  - **Parse error or null result:**
    1. Rename the file to `config.json.corrupt-<yyyyMMddHHmmss>` (from `TimeProvider`).
    2. Try `config.json.bak`. If that is valid, the status is `RecoveredFromBackup` (and it is saved as `config.json`).
    3. Otherwise use the default with status `ResetAfterCorruption`.
  - **`Version > CurrentVersion`:** load the config as-is, `IsReadOnly = true`, status `NewerVersionReadOnly`. A later `Save` throws `InvalidOperationException`.
  - **Every successful load** runs `ConfigValidator.Repair`. If it reports repairs, the repaired config is saved (unless read-only).
  - **Save is atomic:**
    1. Create the directory.
    2. Write `config.json.tmp` via a `FileStream` and `Flush(true)`.
    3. If `config.json` exists, copy it over `config.json.bak`.
    4. `File.Move(tmp, config, overwrite: true)`.
- `ConfigValidator.Repair(AppConfig) → (AppConfig Config, IReadOnlyList<string> Repairs)`:
  - Drop accounts with an id not matching `^[a-z0-9]+(-[a-z0-9]+)*$`.
  - Drop duplicate ids after the first.
  - No default → insert `Account.CreateDefault()` at index 0 (if the id `standard` is taken by a non-default, that one becomes the default).
  - Multiple defaults → keep the first, set `IsDefault=false` on the others.
  - Invalid colors → `NextFreeColor`.
  - Empty names → the id.
  - `LastAccountId` unknown → null.
  - Each repair adds a short English description string (for the log).
- `DefaultConfigFactory.Create()`: version 1, `[Account.CreateDefault()]`, `new AppSettings()`.

Tests cover:
- PathStyle join
- resolver for default and profile in both styles
- McaccPaths with and without `MCACC_HOME`
- PathComparer: trailing separators, mixed separators, case, `..` escape
- palette
- validator: every rule
- store: missing, round trip incl. unknown extra fields, `.bak` written on the second save, corrupt → backup recovery, corrupt without backup → reset (and quarantine file exists), newer version → read-only and Save throws

## Task 4: Core – accounts, config copy, guarded deletion

**Accounts/**
- `SlugGenerator.Generate(string name, Func<string, bool> isTaken) → string`, steps in order:
  1. Trim and lowercase (invariant).
  2. Replace ä→ae, ö→oe, ü→ue, ß→ss, æ→ae, ø→oe, å→aa.
  3. Normalize to NFKD and drop non-spacing marks.
  4. Replace every run of chars outside `[a-z0-9]` with `-`, then trim `-`.
  5. Cut to 32 chars and trim a trailing `-`.
  6. If empty, use `account`.
  7. If the candidate is reserved (`standard`, `default`, `con`, `prn`, `aux`, `nul`, `com1`–`com9`, `lpt1`–`lpt9`) or `isTaken`, try `<candidate>-2`, `-3`, … until free.
  - Tests: "Privat"→`privat`, "Kunde Müller & Söhne"→`kunde-mueller-soehne`, "  "→`account`, "con"→`con-2`, "Standard"→`standard-2`, taken `privat` → `privat-2` (and `-3` when `-2` is also taken), a 50-char name is cut to ≤ 32 without a trailing `-`, "Café"→`cafe`.
- `NameValidationError` enum: `Empty`, `TooLong`, `Duplicate`.
- `AccountNameValidator.Validate(string name, IEnumerable<Account> existing, string? exceptId) → NameValidationError?`:
  - Uses the trimmed name.
  - A name over 40 chars is `TooLong`.
  - A duplicate is a case-insensitive match against the trimmed names of the other accounts.
- `AccountService`: constructor `(IConfigStore store, McaccPaths paths, AccountPathResolver resolver, ConfigCopier copier, ProfileDataDeleter deleter)`.
  - Loads on construction and exposes `ConfigLoadResult LoadResult` and `AppConfig Config`.
  - `CreateAccountResult Create(string name, string color, CopyRequest? copy)`:
    - Validates the name and throws `AccountValidationException(NameValidationError)`.
    - Slug `isTaken` = id exists **or** `Directory.Exists(paths.ProfileDir(slug))`.
    - Creates `desktop/` and `claude/`.
    - Runs the copy if requested and appends the account.
    - Saves, and returns the account plus `CopyReport?`.
  - `Account Update(string id, string name, string color)`: the name is validated excluding self. The id never changes.
  - `void Remove(string id, bool deleteData)`:
    - Throws `InvalidOperationException` for the default account or an unknown id.
    - Deletes data via the deleter if requested, **before** removing it from the config.
    - Clears `LastAccountId` if it pointed there, then saves.
  - `void UpdateSettings(Func<AppSettings, AppSettings> change)`: saves.
  - (The "blocked while Desktop runs" rule is enforced in the App layer.)

**ConfigCopy/**
- `CopyItem` enum: `ClaudeMd`, `SettingsJson`, `Agents`, `Skills`, `Commands`, `Scripts`, `DesktopMcpConfig`.
- `CopyItems.Info(CopyItem) → (string RelativePath, bool IsDirectory, CopyLocation Location)`:
  - `CLAUDE.md` file, ClaudeDir
  - `settings.json` file, ClaudeDir
  - `agents`, `skills`, `commands`, `scripts`: directories, ClaudeDir
  - `claude_desktop_config.json` file, DesktopDir
- `CopyRequest` sealed record: `string SourceAccountId`, `IReadOnlySet<CopyItem> Items`, `bool RewriteSettingsPaths`.
- `ConfigCopyPlanner`:
  - `IReadOnlySet<CopyItem> Available(AccountPaths source)`: exists on disk. `DesktopMcpConfig` is checked against the first existing `DesktopDataDirs` candidate.
  - `CopyPlan Plan(AccountPaths source, AccountPaths target, CopyRequest req)`: returns operations `(CopyItem Item, string SourcePath, string TargetPath, bool IsDirectory, bool RewritePaths)`. `RewritePaths` is only set for SettingsJson when requested. Items not available are skipped.
- `ConfigCopier.Execute(CopyPlan plan, AccountPaths source, AccountPaths target) → CopyReport` (lists copied items and skipped items with reason):
  - Never overwrites an existing target file.
  - Copies directories recursively.
  - Skips reparse points / symlinks (`FileAttributes.ReparsePoint` / `LinkTarget != null`).
  - SettingsJson with rewrite goes through `SettingsPathRewriter`.
  - Only the whitelist is ever copied, so plugins, credentials, history, projects and sessions can never be copied.
- `SettingsPathRewriter.Rewrite(string json, string sourceClaudeDir, string targetClaudeDir, bool sourceIsDefault) → string`:
  - Replaces references to `sourceClaudeDir` in three spellings:
    - raw (`C:\Users\x\.claude`)
    - JSON-escaped (`C:\\Users\\x\\.claude`)
    - forward-slash (`C:/Users/x/.claude`)
  - If `sourceIsDefault`, also replaces `~/.claude` and `$HOME/.claude`.
  - The replacement uses the same spelling style with the target path; for the `~` and `$HOME` forms it uses the forward-slash absolute target.
  - A match must be followed by end of string, `/`, `\`, `"`, `'` or whitespace, so `.claude.json` and `.claude-x` stay untouched. Matching is case-insensitive.
  - Tests cover all forms and the negative cases.

**ProfileDataDeleter.Delete(Account account, McaccPaths paths)`:**
- Throws for the default account.
- Target = `paths.ProfileDir(account.Id)`. It must be `IsStrictlyUnder(target, paths.ProfilesDir)`, otherwise throw.
- Clears read-only attributes recursively, then `Directory.Delete(recursive)`.
- A missing directory is not an error.
- Tests: default refused, `..` id refused (construct an Account with a bad id directly), normal delete, read-only file inside.

## Task 5: Core – quoting, process specs, terminal builders and planners

**Processes/**
- `ProcessSpec` sealed record: `string FileName`, `IReadOnlyList<string> Arguments`, `string? WorkingDirectory`, `IReadOnlyDictionary<string, string> EnvSet`, `IReadOnlyList<string> EnvUnset`.
- `EnvironmentScrub.Always = ["CLAUDECODE", "CLAUDE_CODE_ENTRYPOINT", "CLAUDE_CODE_SSE_PORT"]` and `ClaudeConfigDirVariable = "CLAUDE_CONFIG_DIR"`.
- `LineEnding` enum: `Lf`, `CrLf`.
- `LaunchFile` sealed record: `string Path`, `string Content`, `LineEnding LineEnding`, `bool Executable`.
- `TerminalLaunchPlan` sealed record: `ProcessSpec Process`, `IReadOnlyList<LaunchFile> Files`.
- `LaunchFileWriter.Write(LaunchFile f)`: creates the directory, normalizes the content to the given line ending, writes UTF-8 **without BOM**. If `Executable` and not Windows, sets `UnixFileMode` 0700.
